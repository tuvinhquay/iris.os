# CI MINI Module
Hệ thống CI/CD thu nhỏ để kiểm tra và báo cáo tình trạng dự án.
- Kiểm tra cú pháp (Syntax Checker).
- Kiểm tra runtime (Runtime Checker).
- Kiểm tra build APK (Build Checker).
- Kiểm tra kết nối Firebase (Firebase Checker).
- Kiểm tra Gemini API (Gemini Checker).
- Báo cáo qua Telegram (Telegram Reporter).
